# Stanford CME 295 · Transformers & Large Language Models

**Autumn 2025** 的 9 讲课程归档。课程从 Transformer 与 NLP 基础出发，依次覆盖模型结构、训练、preference tuning、reasoning、agents、evaluation，最后讨论多模态与 diffusion。每讲预览结合官方 slides 与 Stanford Online 视频章节；提供逐讲补充阅读线索和全课 Guidance。

课程面向具备 calculus、linear algebra 和基础 machine learning 知识的学习者。9 段视频合计约 **16 小时 11 分钟**。此处保留历史课程日历，不将 YouTube 后续上传日期当成授课日期。

## 学习顺序

先读 [全课 Guidance](GUIDANCE.md)，每讲预览中的时间链接可跳回原视频；slides 与视频互为补充。该课程没有在 syllabus 表中列出逐讲 assigned readings，因此 readings.md 标为**补充阅读**，主要选自 slides 引用的原始论文，不代表教师指定必读。

## 整理范围

共 9 套官方 slides 和 9 个 Stanford Online 视频。中文预览按课件结构和视频章节导航编写，保留 Transformer、RoPE、LoRA、GRPO 等技术术语。当前归档不含自动语音转写稿；课程视频与 slides 仍请通过上方官方链接访问。
