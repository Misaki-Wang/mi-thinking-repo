# W13.1 · Readings guidance

## 官方安排与证据

[课程表](https://mit-mi.github.io/mmai-course/spring2026/schedule/)没有为本节指定 Readings。已核对[AI for Cities and Mobility 讲义](https://mit-mi.github.io/mmai-course/spring2026/schedule/lec13.1%20-%20cities.pdf)。下面的顺序为个人复习建议，不新增官方 paper。

## 建议顺序

1. **优先：pp7–30，定义成功和系统边界。** 从 safety、sustainability、affordability 中选两个目标；提取讲义的 stakeholder framework，写出谁的成功可能意味着另一方成本上升。历史数字只记录其年份及来源，不更新成无日期的事实。
2. **核心：pp33–49，理解 GLIN。** 列出 graphs / language / images / numbers 的观测对象、空间时间尺度和缺失模式。回答：为什么它们可以谈论同一城市，却不能直接按行拼接？
3. **方法审读：pp60–77。** 对照 AI function 与 human role，再阅读 Grounded AI 的问题。提取 domain theory 和 DNN 的长处、失效方式、结合位置；不要把“predict”与“explain”当同一个任务。

## 本节交付物

写一份 city-model brief：目标、stakeholders、GLIN data map、human decision point、deployment metric、failure cost。用同一数据分别构造一个 prediction question 和一个 policy question，并指出后者还缺少哪些证据。

自测：为什么 wicked problem 没有简单 stopping rule？一套统一 embedding 会不会消除城市规划的价值判断？哪个 stakeholder 能发现平均误差看不到的失败？
